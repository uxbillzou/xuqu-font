# Historical reference fonts

These are the exact approved v1.3 binaries, preserved byte-for-byte for geometry,
advance and coverage comparisons. Their original embedded metadata and original
README describe that historical build. The owner subsequently authorized SIL
OFL 1.1 for the complete Xuqu family, including these font designs, on 2026-09-13.
