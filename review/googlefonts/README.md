# Google Fonts intake templates

METADATA.pb.in is not a live metadata file and is not used to make the offline QA appear complete. The owner has approved Xuqu, Xu Zou and the family-wide OFL grant. The repository is https://github.com/uxbillzou/xuqu-font. The source commit and intake date remain for the onboarder to set using actual release facts. In particular, the final commit hash and date_added must not be invented. An onboarder should confirm subsets and the reachability of private-use/auxiliary symbols. Upstream font files may contain glyphs that Google Fonts will not serve.

Format reference: https://github.com/google/fonts/blob/main/ofl/abel/METADATA.pb
Workflow: https://googlefonts.github.io/gf-guide/making-pr.html

The public-family name and designer profile must agree with the approved intake information. The owner need not manually edit this template; the technical maintainer/onboarder can generate the final metadata.
